Prompt for Claude

You are a senior QA lead and test reporting specialist. Review the pytest results for the CIAP project and generate a professional QA Test Execution Report.

Instructions:
- Analyze the pytest execution output and summarize all test results.
- Highlight boundary violations separately from other test failures.
- Identify which business thresholds failed, including income, DTI ratio, credit score, employment years, LTV, and down payment percentage.
- Provide a table of boundary test results with columns for Rule, Boundary Case, Expected, Actual, Status, and Severity.
- Classify every failure as Critical, High, Medium, or Low.
- Suggest practical fixes for business rule violations and validation gaps.
- Produce a report suitable for engineering teams, QA teams, product managers, and stakeholders.

Report Structure:
1. Executive Summary
2. Project Overview
3. Test Environment
4. Methodology
5. Test Categories
6. Execution Summary
7. Boundary Value Analysis Results
8. Defects Found
9. Risk Analysis
10. Recommendations
11. Conclusion

Analysis Requirements:
- Pass/fail summary
- Success rate
- Failure categorization
- Severity classification
- Root cause analysis
- Boundary value analysis results
- Security findings
- Performance insights
- Coverage gaps
- Risk assessment

Output Requirements:
- Use concise executive-level language.
- Include a clear table for boundary test results.
- Highlight any high-risk defects or untested areas.
- Ensure the report is professional, structured, and ready for stakeholder review.
